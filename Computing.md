## Computing recherche

### Computing

Computing (auch Informatik oder Rechentechnik) ist die Wissenschaft und Praxis der systematischen Verarbeitung von Informationen, insbesondere der automatischen Verarbeitung mittels digitaler Computer. Es umfasst die Entwicklung von Algorithmen, Datenstrukturen, Software und Hardware zur Lösung komplexer Probleme in verschiedenen Anwendungsbereichen.

**Beispiele:** Entwicklung von Apps und Websites, Künstliche Intelligenz und maschinelles Lernen, Datenanalyse und Big Data, Computerspiele, Robotik, medizinische Bildgebung, Online-Banking-Systeme.

### Computational Thinking

Computational Thinking (deutsch: informatisches Denken) ist ein Problemlösungsansatz, der charakteristische Denkweisen der Informatik auf verschiedene Bereiche überträgt. Es umfasst vier Kernkomponenten: Dekomposition (Zerlegung komplexer Probleme in kleinere Teile), Mustererkennung (Identifikation von Ähnlichkeiten und Regelmäßigkeiten), Abstraktion (Fokussierung auf wesentliche Merkmale) und Algorithmen (Entwicklung schrittweiser Lösungsverfahren).

**Beispiele:** Aufgaben in kleinere Schritte unterteilen (wie beim Kuchenbacken), Muster in Daten erkennen (wie wiederkehrende Verkaufstrends), komplexe Sachverhalte vereinfachen (wie Landkarten), schrittweise Anleitungen erstellen (wie Kochrezepte oder Bauanleitungen).

### Programm

Ein Programm ist eine Folge von Anweisungen, die in einer Programmiersprache geschrieben sind und von einem Computer ausgeführt werden können. Programme bestehen aus Algorithmen, die in einer für den Computer verständlichen Form kodiert sind, sowie aus Datenstrukturen zur Organisation und Verwaltung von Informationen. Sie dienen dazu, spezifische Aufgaben zu automatisieren und Probleme systematisch zu lösen.

**Beispiele:** Textverarbeitungsprogramme (wie Microsoft Word), Webbrowser (wie Chrome oder Firefox), Smartphone-Apps (wie WhatsApp oder Instagram), Betriebssysteme (wie Windows oder macOS), Videospiele, Online-Shopping-Websites.

### Code, Quellcode und Maschinencode

Code ist die allgemeine Bezeichnung für in einer Programmiersprache geschriebene Anweisungen. Quellcode (Source Code) ist der vom Menschen lesbare und bearbeitbare Code, der in einer höheren Programmiersprache wie Python, Java oder C++ geschrieben wird. Maschinencode (Machine Code) hingegen ist die binäre Form des Codes (bestehend aus 0en und 1en), die direkt vom Prozessor verstanden und ausgeführt werden kann. Der Quellcode muss durch einen Compiler oder Interpreter in Maschinencode übersetzt werden.

**Beispiele:** Quellcode in Python (`print("Hello World")`), kompilierter Maschinencode (binäre Zahlenfolgen wie `01001000 01100101`), Zwischenformen wie Bytecode oder Assemblersprache.

### Programmbeschreibung / Programmspezifizierung

Eine Programmbeschreibung oder Programmspezifizierung ist eine detaillierte Dokumentation, die beschreibt, was ein Programm tun soll, bevor es tatsächlich programmiert wird. Sie definiert die Anforderungen, Funktionen, Eingaben, Ausgaben und das erwartete Verhalten des Programms. Dies dient als Grundlage für die Entwicklung und hilft dabei, Missverständnisse zu vermeiden und die Qualität des Endprodukts sicherzustellen.

**Beispiele:** Lastenheft für eine Banking-App (welche Funktionen sie haben soll), Spielregeln für ein Computerspiel, Anforderungsdokument für eine Website, User Stories für eine Shopping-App, technische Spezifikationen für eine Datenbank.

### Unterschied formaler und natürlicher Sprache

Natürliche Sprache ist die alltägliche menschliche Kommunikation (wie Deutsch oder Englisch), die mehrdeutig, kontextabhängig und flexibel ist. Formale Sprache hingegen folgt strengen, eindeutigen Regeln und Strukturen, wie sie in der Mathematik, Logik und Programmierung verwendet werden. Programmiersprachen sind formale Sprachen, die präzise Anweisungen ohne Mehrdeutigkeiten ermöglichen, damit Computer sie korrekt interpretieren können.

**Beispiele:** Natürliche Sprache: "Mach das Licht an" (mehrdeutig), Formale Sprache: `if (button_pressed) { light = ON; }` (eindeutig), mathematische Formeln, Programmcode, logische Aussagen wie "WENN-DANN-Regeln".
